01 · ColourTaken from the app, named by job

Names describe what a colour does, so the next designer knows when to use it. The partner's teal is a token too, so loan screens stay recognisable.

action#6A35EFPrimary buttons, links, active tab.
balance-surface#EBE9FFThe balance card. Nothing else.
canvas#F7F6FBApp background behind white cards.
ink#1C1B3ANames, amounts, titles.
earn#16B48CMoney coming in: earnings, refunds, success.
partner-credit#02A59CFlexiMFB loan screens only.
badge#FF8A1F"0 Fee", "Promo", "Hot". Small, rare.
alert#E5484DUnread counts and real errors. Never for a customer who did nothing wrong.

04 · Content rulesHow PalmPay talks about credit

Do"You pay back ₦25,600 on Tue 10 Nov."
Amount, total and date in one sentence, before the button.
Don't"Loanable Amount up to ₦2,000,000" when the limit is ₦2,000.
Show what this customer can actually get.
Do"Nothing is sent until you confirm."
Say when money moves.
Don'tStart a paid plan from a "Free for 1st month" tap without a reminder before the first charge.

05 · In codeTokens a developer can use today

/* pp-ui.css · tokens */
.pp {
  --pur: #6A35EF;     /* action */
  --lav: #EBE9FF;     /* balance surface */
  --bg: #F6F5FC;      /* canvas */
  --ink: #1C1B3A;     /* ink */
  --green: #16B48C;   /* earn */
  --teal: #02A59C;    /* partner credit (FlexiMFB) */
  font-family: -apple-system, "SF Pro Text", Inter, sans-serif;
}

// pp-ui.js · screens are functions of state
S.offer({ d: 14 })        // ₦22,800 due Tue 27 Oct
S.offer({ d: 28 })        // ₦25,600 due Tue 10 Nov
S.track({ done: true })   // "₦5,000 is back in your balance"
